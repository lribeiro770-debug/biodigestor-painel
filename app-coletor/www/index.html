    ESP

    O token é o mesmo dos comandos MQTT (configurado no firmware). Por segurança, o Android só permite HTTP sem criptografia para 192.168.4.1 e biodigestor.local.

    Rede Wi-Fi do biodigestor

    Deixe Biodigestor-XXXX para aceitar qualquer rede que comece com “Biodigestor-”. Usado no botão “Conectar” (Android 10 ou mais novo).

    GitHub
    Como criar o token do GitHub
    1. No navegador, entre em github.com com a conta que tem acesso ao repositório.
    2. Vá em Settings → Developer settings → Personal access tokens → Fine-grained tokens e toque em Generate new token.
    3. Nome: “Coletor Android”. Validade: a que o grupo preferir (ex.: 90 dias).
    4. Resource owner: o dono do repositório (ex.: lribeiro770-debug).
    5. Repository access → Only select repositories → escolha só biodigestor-painel.
    6. Permissions → Repository permissions → Contents: Read and write. Não marque mais nada (Metadata: Read-only entra sozinho).
    7. Gere, copie o token (github_pat_…) e cole acima. Ele fica salvo só neste celular.
